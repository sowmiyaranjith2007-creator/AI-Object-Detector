# 🤖 AI Object Detector

An AI-based Object Detection web application built using **Python, Flask, YOLO, and OpenCV**.

The application allows users to upload an image and automatically detects objects present in the image using the YOLO deep learning model.

## 📌 Project Description

AI Object Detector is a simple and user-friendly web application for detecting objects in images.

Users can upload an image through the web interface. The YOLO model processes the image, identifies objects, and displays the detection results with bounding boxes.

## ✨ Features

- 📷 Upload images
- 🤖 AI-based object detection
- 📦 Bounding boxes around detected objects
- ⚡ Fast image processing
- 🌐 Flask-based web interface
- 🧠 YOLO object detection model
- 🖼️ Detection result displayed on the webpage

## 🛠️ Technologies Used

- Python
- Flask
- YOLO
- Ultralytics
- OpenCV
- HTML
- CSS
